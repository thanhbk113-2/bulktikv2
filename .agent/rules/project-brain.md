# Global Coding Rules (Áp dụng cho mọi dự án)

## Nguyên tắc bắt buộc (Tiết kiệm Token & Đơn giản hóa)

1. **KHÔNG tự ý đọc toàn bộ file hoặc quét cả workspace** khi task chỉ liên quan một phần nhỏ hoặc đã chỉ định file/hàm cụ thể. Chỉ đọc đúng đoạn liên quan.
2. **Code tối giản hết mức:** Viết ngắn gọn, thẳng vào vấn đề, ưu tiên giải pháp đơn giản có sẵn. Không tự ý cài thêm thư viện, tách nhỏ file hay trừu tượng hóa phức tạp khi không được yêu cầu.
3. **Sửa đúng trọng tâm:** Giữ nguyên cấu trúc, tên biến/ID/class và logic cũ đang chạy ổn. Khi trả lời code, chỉ xuất phần cần sửa/thêm kèm vị trí rõ ràng, không in lại toàn bộ file lớn.
4. **Ngắn gọn khi giao tiếp:** Trả lời thẳng trọng tâm bằng tiếng Việt, bỏ qua lời chào hay giải thích dài dòng.
